# Architecture détaillée

Le laboratoire repose sur un serveur de domaine et un ou deux clients Windows reliés à un réseau virtuel interne. `SRV-AD01` héberge les rôles AD DS, DNS et DHCP uniquement pour l'apprentissage.

## Flux nécessaires

Les flux seront documentés à partir des besoins réels d'Active Directory. Aucune règle `any/any` ne sera considérée comme une configuration finale.
